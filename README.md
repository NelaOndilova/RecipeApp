Recipe App
Tato aplikace byla vytvořena jako ročníková práce. Jedná se o jednoduchou mobilní Android aplikaci pro ukládání a správu receptů.
Co aplikace umí:
- zobrazit seznam receptů  
- vyhledávat podle názvu  
- filtrovat podle kategorií  
- přidávat nové recepty  
- označit recept jako oblíbený ❤️  
Použité technologie:
- Kotlin  
- Android Studio  
- Jetpack Compose  
- Room Database
